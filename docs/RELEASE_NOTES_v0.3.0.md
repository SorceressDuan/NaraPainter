# v0.3.0 — 那菈绘梦 / Nara Painter

在 v0.2.0 的基础上补齐四件事：**污点修复、文字工具、图层编组、合并**。都是原项目里有、
这个移植版之前没有的功能。同时把撤销栈从「逐项记录」改成「整份快照」，
让结构性的操作（建组、解组、删除、合并）也能一步还原。

**下载**：`NaraPainter-0.3.0-win-x64.zip`（149.69 MB）

- 解压后双击 `launcher\NaraPainter.exe` 启动；想放桌面就再双击 `创建桌面快捷方式.bat`
- 便携版，**无需安装 .NET 或 Windows App SDK**

---

## 新增功能

### 污点修复（`J`）

在瑕疵上按住拖动，划出要修的范围，松手时用周围的纹理补回来。
和内容感知填充的区别是**它不需要先做选区**，直接涂就行。

三种补法，对应原项目 `HealPixels.c` 的三种内核：

| 模式 | 做法 |
| --- | --- |
| 内容感知 | 从四周找最像的纹理块补进来 |
| 生成纹理 | 按周围纹理自己长一块出来 |
| 邻近匹配 | 就近取一块相似纹理 |

笔刷的大小、硬度、不透明度可以在右侧属性面板调，也可以按 `J` 切换开关。

**已知限制**：修复只在**和画布同尺寸**的图层上有效。裁剪或旋转会改变图层像素而不改变画布，
这种情况下工具会跳过并提示，而不是硬涂上去把画面弄脏。

### 文字工具（`Ctrl+T`）

按 `Ctrl+T` 进入放置状态，在画布上点一下定位，弹出输入框，确定后生成一个文字图层。
文字图层和普通图层一样，能改名、调不透明度、换混合模式、参与编组、被合并，也能撤销。

**已知限制**：目前只有一种字体与字号，生成的是**已栅格化**的图层，
不能回头再改文字内容或字号。可重排的文字图层在待办里。

### 图层编组

图层面板支持文件夹了：`Ctrl+G` 把选中图层建成组，`Ctrl+Shift+G` 解组，
拖动图层可以放进文件夹，文件夹可以折叠。

- 折叠状态**不进撤销栈**——"看点"不是文档的一部分。
- 文件夹是**穿透**的：文件夹的不透明度和可见性会乘到里面每一层上，而不是先合成成一个整体。
  对混合模式不是「正常」的子图层来说，先合成再叠加和穿透的结果**并不一样**，所以选了穿透。

### 合并（`Ctrl+E`）

`Ctrl+E` 合并：选中的是文件夹就合并整组，否则向下合并。`Ctrl+Shift+E` 显式合并组。
面板底部也有两个按钮。

合并结果 = 这组图层在画布上**呈现出来的样子**：混合模式、不透明度、蒙版、
组内的调整层全部烘焙进去。**自己下面那些图层不参与**，所以合并永远不会改变文档其余部分的外观。

- 向下合并：选中层 + 它**同父**的下一个兄弟层。跨文件夹边界、下面是文件夹、下面是调整层都拒绝。
- 合并组：整个子树，**嵌套的子文件夹也一起收走**（否则会在面板上留下空文件夹）。
- 一步 `Ctrl+Z` 全还原。

## 撤销栈的改动

原来的撤销栈把每个操作记成一条「反过来做一遍」的指令。这对移动、改名这类操作合适，
但对建组、解组、删除、合并这种**结构变化**很容易漏掉中间状态——删除一个文件夹时，
子图层的归属关系就没人还原。

现在这几种操作改成**存整份图层栈的快照**：记录的是有哪些行、什么顺序、谁是谁的父级、混合模式与蒙版，
撤销时整个还原。快照**只存指针，不复制像素**——20 个 4000×3000 的图层如果每步都拷像素，
一步就是约 960 MB；存指针的话 1000 个图层也才 8 KB 左右。

## 快捷键变化

**`Ctrl+E` 从「导出」改成「向下合并」**，导出改为 **`Ctrl+S`**。
原项目的 `Cmd+E` 就是合并，这次对齐它；导出本来就没有自己的键位，`Ctrl+S` 是空着的。

完整快捷键表见 [README.md](../README.md#快捷键)。

## 界面

图层面板重新排过：**行高从约 280 px 降到 68 px**，一屏能看的图层数从 2 个变成 6~8 个
（取决于窗口高度），横向也不再裁切。每行两排：上面是名称与尺寸，下面是不透明度滑条、
数值框和混合模式下拉框。

修掉一个拖拽后才暴露的显示问题：折叠的图层原先是用「藏起来」的方式留在列表里，
ListView 回收容器时会把它们算到视口外很远的地方，拖拽后图层行会叠在一起。
现在折叠的行**直接从列表里去掉**，没有容器可回收，问题消失。

## 系统要求

- **Windows 10 1809（build 17763）或更高**，64 位
- **不需要安装 .NET**，也不需要 Windows App SDK；运行时随包提供
- 约 300 MB 磁盘空间（解压后）

## 已知问题

- **图层面板的混合模式下拉框在切换界面语言后会短暂空白**，点开一次即恢复。
  底层数据是对的（图层混合模式没有被改动），只是 WinUI 已关闭的下拉框不重绘选中项文本。
- **面板拖拽的手感还没做细**：文件夹目前能被拖进自己的子层（逻辑上应当拒绝），
  而且分不清「放在文件夹上面」和「放进文件夹里面」。计划按资源管理器的落点规则重做。
- **污点修复还没有真机手感验证**（自检和单元测试都过了，但手感没人手工试过）。
- 首次运行可能出现 SmartScreen 提示，选「更多信息」→「仍要运行」。
- 安装包（MSIX）**未随本版本提供**：签名证书无法在当前构建环境生成，详见 `installer/README.md`。

## 这个版本不做什么

本工具定位为**轻量级编辑器**，不做 Photoshop 的替代品。完整清单见
[docs/MISSING_FEATURES.md](MISSING_FEATURES.md)，要点：

可重排的文字图层、修复画笔 / 仿制图章、完整画笔引擎与橡皮擦、图层样式（投影 / 描边 / 发光）、
矢量工具（路径 / 形状图层 / 矢量蒙版）、PSD 导入导出、CMYK、RAW、智能对象、
动作与批处理、插件体系。
