# 缺失功能清单

本工具定位为**轻量级图像编辑器**（非官方移植版），目标是打开大图、做常用调整、导出——**不是 Photoshop 的替代品**，
也不打算追赶专业级功能。这份清单如实列出当前没有的东西，按使用频率分类，供你在选型时建立预期。

标注口径：

- **不实现**：与「轻量级编辑器」的定位冲突，本项目不会做
- **未实现**：属于合理范围，但当前版本没有，后续可能补
- 括号内是当前可用的替代做法（如果有）

---

## 高频

缺少这些会让日常编辑明显不顺手。

| 功能 | 状态 | 说明 / 替代 |
| --- | --- | --- |
| **文字工具**（添加/编辑文字图层） | 部分 | **基础版已实现**：工具栏「文字」或 `Ctrl+T` 进入，在画布上点击定位 → 弹窗只输入文字 → 生成可撤销的文字图层。**只有单一字体（Microsoft YaHei UI）、固定字号 64px、近黑色**；没有字体/字号/颜色/对齐选择、没有行内编辑与段落框，且**栅格化后不可再编辑** |
| **完整画笔引擎** | 部分 | 只有**蒙版画笔**（大小/硬度/不透明度/擦除/羽化）。不能按颜色在图层上画，没有压感、笔刷预设、笔尖形状 |
| **橡皮擦** | 未实现 | 只有蒙版画笔的「擦除」模式，它擦的是蒙版不是像素 |
| **自由变换** | 部分 | 已有 90° 旋转与水平/垂直翻转；**不能**任意角度旋转、缩放或透视变形图层 |
| **另存为 / 保存回文件** | 未实现 | 只有导出。没有「保存」概念，导出是在导出对话框里选路径 |
| **选区工具** | 部分 | 只有矩形和椭圆选区，且是数值输入（X/Y/宽/高）。没有套索、魔棒、快速选择、选区加减运算 |
| **移动工具** | 未实现 | 图层不能被拖动位移。位置由内容决定 |
| **色阶 / 曲线的吸管取样** | 未实现 | 色阶与曲线可调，但没有在图上点选来定位黑白点的吸管 |

## 中频

用得上，但不影响最简单的流程。

| 功能 | 状态 | 说明 / 替代 |
| --- | --- | --- |
| **修复画笔 / 污点修复 / 仿制图章** | 部分 | **污点修复已实现**（大小/硬度/不透明度，内容感知・生成纹理・邻近匹配三种模式）。**修复画笔与仿制图章仍未实现**；这两者要的是「按 Alt 指定源点后手动取源」，与污点修复的自动找源不是一回事。内容感知填充仍是最接近的替代 |
| **图层样式**（投影、内阴影、外发光、描边、斜面和浮雕） | 未实现 | 只有图层的混合模式与不透明度 |
| **图层组 / 编组** | 未实现 | 图层是平铺列表，不能编组、不能嵌套 |
| **图层蒙版的手工绘制** | 部分 | 有蒙版画笔与选区转蒙版，但没有蒙版缩略图预览、没有蒙版与图层间的链接控制 |
| **矢量工具**（路径、形状图层、矢量蒙版） | 未实现 | 只有选区的矩形/椭圆形状，不是可编辑路径 |
| **多步历史面板** | 部分 | 撤销/重做可用（含每步名称），但没有可跳转的历史记录面板 |
| **画布辅助**（标尺、参考线、网格、吸附） | 未实现 | 无 |
| **图像尺寸调整 / 重采样** | 已实现 | 画布尺寸可改（可保持长宽比），导出时也能改尺寸与质量 |
| **批量处理 / 动作** | 未实现 | 无动作录制、无批处理、无脚本接口 |
| **色彩调整的更多项**（色彩平衡、通道混合器、渐变映射、可选颜色、阴影高光） | 未实现 | 现有：亮度/对比度、色相/饱和度、色阶、曲线 |
| **图层对齐 / 分布** | 未实现 | 无 |
| **打开多张图 / 多文档标签页** | 未实现 | 一次只有一个文档 |

## 明确不实现（专业级深水区）

这些不是「还没做」，而是**在轻量级定位下决定不做**。写在这里是为了让预期明确，
也给后来接手的人一个交代：不要在这上面花时间，除非项目定位整体改变。

| 功能 | 说明 |
| --- | --- |
| **PSD / PSB 导入导出** | 格式本身承载了图层、蒙版、样式、矢量、文字、智能对象等一整套语义。做不完整的 PSD 支持比不做更糟——用户会以为图层结构能往返，结果拿到的是拍平的图 |
| **CMYK 色彩管理** | 只有 RGB（8 位/通道）。CMYK 涉及分色、油墨总量、ICC 特性文件与软打样，是印前流程的一整套体系，不是加一个枚举值 |
| **RAW 支持** | 相机 RAW 解码要跟各家传感器的马赛克算法、白平衡、镜头校正数据库打交道，任何自研实现都不可能达到 Lightroom 的水平 |
| **智能对象** | 依赖非破坏性的嵌套文档与变换栈，本质是一套独立的文档模型 |
| **矢量路径** | 需要完整的路径布尔运算、贝塞尔编辑、描边填充模型。当前只有选区的矩形/椭圆，不是可编辑路径 |
| **动作与批处理** | 需要可记录的操作序列与回放引擎。当前撤销栈记的是状态对，不是可序列化的动作脚本 |
| **插件系统** | 无插件接口、无扩展点，也不打算开放。跨进程稳定 ABI 的设计成本远高于本项目本身 |

需求这些能力时，请继续使用 Photoshop、Affinity Photo 或 GIMP。

## 当前**能**做什么

为了让上面的清单有参照，这是现有能力：

- **打开**：PNG / JPEG / BMP / WebP / TIFF，含 4000×3000 级别的大图（参考 190 ms 左右）
- **图层**：新建、复制、删除、重排、重命名、显示/隐藏、不透明度、**24 种混合模式**（含全部 W3C 非分离模式）
- **调整图层**：亮度/对比度、色相/饱和度、色阶、曲线
- **选区与蒙版**：矩形/椭圆选区、羽化、应用为蒙版、全选、清除；**蒙版画笔**（大小/硬度/不透明度/擦除）
- **内容感知填充**：按选区或蒙版挖洞自动补内容（Telea / Nikolai 两种算法）
- **污点修复**：在瑕疵上拖动，松手时用周围纹理补回来；三种模式（内容感知 / 生成纹理 / 邻近匹配），
  笔刷大小、硬度、不透明度可调，一次拖动记一步撤销；快捷键 `J`
- **文字**：点击定位 → 输入文字 → 生成图层（`Ctrl+T`），可撤销/重做
- **导出**：PNG / JPEG / BMP / WebP / TIFF，可选质量，TIFF 支持四种压缩且保留 alpha
- **几何**：裁剪到选区、顺/逆时针 90° 旋转、水平/垂直翻转、画布尺寸调整（可保持长宽比）
- **吸管**：点画布取色，显示色块与 `#RRGGBB`，一键复制
- **滤镜**：高斯模糊、USM 锐化（可调半径与强度）
- **撤销/重做**：含每步名称，键盘可操作；一次拖动算一步
- **界面语言**：简体中文与 English 即时切换，选择会被记住

## 一句话预期

能替代 Photoshop 完成「打开图 → 调调整图层 → 合层 → 导出」这类工作，**不能**替代它做
排版级文字处理（字体/字号/颜色/对齐、行内编辑、段落框）、
仿制图章与手动取源的修复、矢量绘制、PSD 往返或印刷相关的活。需要那些能力时，请继续使用专业工具；
本工具可以作为轻量补充。
